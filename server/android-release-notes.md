星邮 0.25.1 · 重装账号恢复修复

- 修复卸载重装、启用或重载扩展时，旧账号 ID 配置或缺少 `.env` 密钥挡住恢复入口的问题。
- 初始页「恢复已有账号」支持填写原 ID 或昵称，粘贴原凭据或选择原 `starpost-credential.json` 文件。服务器验证成功后保留原 ID，不占用新的注册名额。
- ID 输入兼容首尾空白和全角数字；已保存的凭据和身份文件优先于旧配置，错误凭据仍会被拒绝。

请更新 Cortico/Coopanion 中的星邮扩展至 **0.25.1**。Android 仍为 **1.7.0（版本码 17）**，本次附带原签名的相同 APK，已安装 1.7.0 的用户无需更新手机应用。
