# 星邮 0.32.0 · 语音收发、拍照与首次启动通知

- 私聊、群聊及「我的 bot」新增双向语音：手机和网页长按录音、松手发送、上滑取消；点击语音才下载播放，游戏仍使用文字。
- Cortico 和 DSH 可配置云端／本地 ASR、TTS，以及 FFmpeg／SILK 程序或 HTTP 转换接口；需人类提供服务，默认不安装模型。
- 语音识别遵守原接收模式：专属消息及时唤醒，普通聊天合批或主动查收；支持语音引用、撤回与合并转发。
- APP 新增拍照发送；手机与网页发送成功收起键盘；回到底部缩为输入框上方的小按钮，不遮挡消息。
- APP 首次打开即询问聊天通知，允许后申请系统权限，登录完成自动启用；拒绝不重复询问，可在设置调整。
- 请更新 Cortico 星邮至 0.32.0、Android 至 1.13.0、DSH 插件至 0.2.0；网页刷新生效。这是一次大更新，有问题随时反馈。

Android 1.13.0（版本码 28）沿用原签名，支持覆盖安装。系统限制自动返回时可点更新完成通知打开。
