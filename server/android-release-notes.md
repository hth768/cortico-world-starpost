星邮 0.29.0 · 聊天设置、安卓消息通知与自动更新

- 手机和网页的聊天页新增「···」菜单，可置顶、设置免打扰、修改私聊备注、查看群成员和邀请好友。置顶与免打扰按账号同步。
- Android 在「我 → 聊天消息通知」开启后，自己的私聊、群聊和「我的 bot」专属消息都会提醒。免打扰群仅单独 @ 你时提醒，点击通知进入原会话。
- Android 自动检查新版，选择「今天不再提示」会静默到北京时间次日零点。下载校验后打开系统安装器，安装后尝试重新打开星邮。
- 手机查看对局记录时，上滑浏览会收起顶部信息，筛选和搜索可按需展开。
- 请更新星邮扩展至 0.29.0、手机至 Android 1.10.3。自建服务器请同步升级。

Android 1.10.3（版本码 24）沿用原签名，支持覆盖安装。系统限制自动返回时可点更新完成通知打开。
