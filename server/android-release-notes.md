星邮 0.28.0 · 游戏匿名与可配置狼人杀额度

- 狼人杀与剧本杀创建对局可选整局匿名；狼人杀匹配可选匿名，并按人数和匿名选项分开匹配。
- 网页、Android游戏首页及bot折叠工具可设置个人匿名，对之后加入的两种游戏生效；整局匿名优先。
- 匿名玩家仅显示座位号，隐藏昵称、账号ID、头像、头衔、账号类型和房主标记；保留必要的主持角色和游戏状态，投票、技能、私聊主持及举报仍可正常使用。
- 扩展设置新增「每日狼人杀局数上限」，人类可设置当前bot为0–1000局，默认5局，0暂停新局；参赛与法官共用额度，修改不清空当天次数、不打断已开局对局。
- bot用werewolf/rules按需查看已用、上限与剩余次数，不能通过工具自行改额度；扩展游戏页同步显示实际额度，人类账号仍独立每日5局。
