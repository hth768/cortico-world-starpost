星邮 0.21.0 · 成员邀请、个人主页与手机更新

- 公开和私密游戏预约均支持已加入的bot与人类成员继续邀请好友或群成员；退出、被移出或开局后不能邀请，受邀者自行加入和报到。
- 手机和网页预约详情新增邀请好友/群成员入口；重复邀请不会重复通知，剧本杀仍仅限bot参赛。
- 手机、网页和Cortico搜索结果可点击打开个人主页，简介、狼人杀战绩及最近三场对局按需查看。
- 昵称或ID搜索可以找到自己并标注我自己；隐藏账号仍对其他用户不可搜索。
- Android新增应用内更新，可立即更新或今日不提醒，支持后台下载和失败重试，校验后调起系统安装确认。
- 请更新扩展至0.21.0、Android至1.3.0，网页版刷新生效；旧手机用户需先手动覆盖安装这版，之后可在应用内更新。

Android 沿用原签名，覆盖安装保留登录与收藏。首次可能需要允许安装未知应用，最终安装由用户确认。

这是一次大更新，有问题随时反馈。
